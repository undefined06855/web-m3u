# web-m3u

A self-hosted m3u generator for playlists!

Start by creating a folder called "music" and place folders containing audio files inside (which are your playlists).

A `config.example.toml` file is placed as an example of a `config.toml` file. Use it as a reference and create your own
`config.toml` file to suit your needs.

Run `bun i` and then `bun main` to start hosting!

## Notes

- If there are more than 4 artists, genres or albums, the auto-generated artist/genre/album list will be
"Various Artists", "Various Genres" or "Various Albums".
- The music directory can be a symlink to somewhere else! Keep in mind, a `.web-m3u-cache` folder will be created to
store album covers and cache song metadata. If a song is modified but the same filename is kept, this folder should be
removed to regenerate metadata.
- The first time you fetch the playlist it may take a **very long time** to respond (especially for large playlists) as
it writes album covers to disk and parses song metadata! Subsequent requests should be extremely fast, since metadata
and album covers will already be cached. It takes around **8 seconds** to parse a 220 song playlist on my server, but only
**100ms** after everything is cached (including networking). This may take longer for servers with slow i/o (though Bun
does read files pretty efficiently).

## Example Setup

With a folder structure as follows:
```
.
├── .gitignore
├── bun.lock
├── main.js
├── package.json
├── README.md
├── tsconfig.json
│
├── config.toml
└── music/
    ├── my-playlist-1/
    │   ├── song-by-me.mp3
    └── epic-playlist/
        └── djrubrub.mp3
        └── config.json
```

Navigating to `http://localhost:8080/my-playlist-1.m3u` then gives the following m3u file:
```
#EXTM3U

#PLAYLIST:My Playlist 1
#EXTALB:Various Albums
#EXTART:Various Artists
#EXTGENRE:Unknown

#Generated by web-m3u: https://github.com/undefined06855/web-m3u

#EXTINF:69.42,Artist - Song By Me
#EXTBYT:1596637
#EXTALBUMARTURL:http://localhost:8080/.cache/1a72131443b25d09.jpg
http://localhost:8080/my-playlist-1/song-by-me.mp3

```

The `config.json` shown in Epic Playlist can contain the following information (which is passed into the .m3u):
```json
{
    "name": "Name of the playlist to override the auto-generated one",

    "group": "Group passed to the EXTGRP tag",

    "album": "Album passed to the EXTALB tag to override the auto-generated one",
    "artist": "Artist passed to the EXTART tag to override the auto-generated one",
    "genre": "Genre passed to the EXTGENRE tag to override the auto-generated one"
}
```
